# Scientific Functional Ambiguity in Inverse Problems

**Mamadou Foune Barry — September 2026**<br>
Preliminary mathematical investigation / technical report.

## Overview

This report studies how scientific quantities can vary among states that are
indistinguishable under a non-injective forward operator. It examines centroid
and linear-fractional functionals, nullspace geometry, positivity and the role
of denominator variation in the relationship between local sensitivity and
finite ambiguity.
